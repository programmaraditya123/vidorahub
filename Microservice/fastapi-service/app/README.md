# app

This is the FastAPI application package for the VidoraVibe microservice. It exposes HTTP endpoints for creating video processing jobs, listing generated Vibes, rendering clips, and serving generated media files.

## How the app starts

- `main.py` creates the FastAPI app, configures CORS, mounts the `/media` static file route, registers exception handlers, and includes API routers.
- `__init__.py` marks this directory as a Python package so modules can be imported with `app...` paths.
- `requirements.txt` lists the Python packages needed by this service.
- `.env` is a local runtime configuration file. Do not commit secrets from this file. Use `../.env.example` as the safe template.

## Main request flow

1. A client calls `POST /api/v1/vibe-jobs` with a supported video URL.
2. `api/routes/vibe_jobs.py` validates ownership headers and URL details.
3. `repositories/` creates or reuses an active MongoDB job.
4. `workers/vibe_worker.py` starts background processing.
5. `services/jobs/processor.py` downloads media, extracts audio, transcribes, analyzes moments, stores Vibes, and optionally renders clips.
6. `api/routes/vibes.py` lets clients fetch, edit, render, download, or publish individual Vibes.

## Folder map

- `api/`: HTTP route modules and request dependencies.
- `core/`: app configuration, MongoDB connection setup, logging, and shared error types.
- `models/`: domain enums and constants used across persistence, APIs, and services.
- `repositories/`: MongoDB access layer for jobs and Vibes.
- `schemas/`: Pydantic request and response models.
- `services/`: business logic for media sources, AI, processing, rendering, and downloads.
- `utils/`: small reusable helpers for URL validation, cleanup, and progress values.
- `workers/`: background worker entrypoints.

## Runtime dependencies

The service expects MongoDB for persistence when job or Vibe endpoints are used. Video processing also needs FFmpeg and ffprobe available on the machine. Optional providers include `yt-dlp` for YouTube, OpenAI for cloud transcription and semantic analysis, and `faster-whisper` for local transcription.

## Generated files

Python creates `__pycache__` folders during execution. They are generated bytecode caches and are safe to delete. They should not be treated as source files.
