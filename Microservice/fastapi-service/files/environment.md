# Environment

- `APP_NAME`: optional service name. Example: `vidoravibe`. Not sensitive.
- `ENVIRONMENT`: optional runtime mode. Example: `development`. Not sensitive.
- `HOST`, `PORT`: optional server bind settings. Not sensitive.
- `MONGODB_URI`: optional for local health checks, required for persistent job and vibe APIs. Leave blank when MongoDB is not running locally. Sensitive when it includes credentials.
- `MONGODB_DATABASE`: required MongoDB database name. Not sensitive.
- `VIDORAHUB_API_URL`: required for publishing. Not sensitive by itself.
- `VIDORAHUB_INTERNAL_API_URL`: required for VidoraHub source acquisition. Sensitive if private.
- `GOOGLE_CLOUD_PROJECT`, `GOOGLE_CLOUD_STORAGE_BUCKET`: optional GCS defaults. Not secrets.
- `YOUTUBE_ENABLED`: optional feature flag. Not sensitive.
- `AI_PROVIDER`, `AI_API_KEY`, `AI_MODEL`: semantic analysis configuration. `AI_PROVIDER=openai` uses OpenAI. `AI_PROVIDER=local` or `heuristic` uses the local scoring fallback. API key is sensitive.
- `TRANSCRIPTION_PROVIDER`, `TRANSCRIPTION_API_KEY`, `TRANSCRIPTION_MODEL`: transcription configuration. `TRANSCRIPTION_PROVIDER=openai` uses OpenAI Whisper. API key is sensitive.
- `LOCAL_WHISPER_MODEL`, `LOCAL_WHISPER_DEVICE`: local Faster Whisper settings when `TRANSCRIPTION_PROVIDER=local`.
- `FFMPEG_PATH`: optional local FFmpeg path. Not sensitive.
- `MEDIA_TEMP_DIR`, `MEDIA_OUTPUT_DIR`: optional media directories. Not sensitive.
- `PUBLIC_MEDIA_BASE_URL`: optional external base URL for rendered media. Use this when rendered files are uploaded to object storage or a CDN.
- `PUBLIC_API_BASE_URL`: API base URL used for local `/media` download URLs.
- `RENDER_VIBES_DURING_JOB`: when true, jobs render Vibe videos before completion.
- `MAX_VIBES_PER_JOB`: maximum generated/rendered Vibes per job.
- `MAX_VIDEO_SIZE_MB`, `MAX_VIDEO_DURATION_SECONDS`: required safety limits. Not sensitive.
- `JOB_TIMEOUT_SECONDS`, `JOB_POLL_INTERVAL_SECONDS`: optional worker and polling limits. Not sensitive.
- `CORS_ORIGINS`: required browser origins. Not sensitive.
- `JWT_SECRET`: required once JWT validation is enabled. Sensitive.
